# Beyond "All Rights Reserved": Modern Copyright Management in Software

Presentation materials on intellectual property and software licensing models,
prepared for the *Methodology and Organization of Scientific Research with the
Fundamentals of Intellectual Property* academic course.

## Overview

Traditional copyright law relies on an explicit permission model that fails to
scale with modern open-source ecosystems and collaborative engineering. This
talk explores how software engineers manage rights programmatically—from public
licenses to CI-driven compliance and machine learning gray areas.

## Key Topics

- **Limits of Classical Copyright:** The shift from individual negotiation to
  automated public offers.
- **Licensing Spectrum:** Permissive (MIT, Apache 2.0) vs. Copyleft (GPL, AGPL)
  vs. Creative Commons for non-code assets.
- **The REUSE Specification:** Implementing per-file SPDX headers and automated
  CI/CD license linting.
- **Modern Challenges:** License incompatibility, source-available pivots
  (BSL/SSPL), and copyright boundaries in LLM training datasets.
